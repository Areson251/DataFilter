# DATASET TOOLS

Репозиторий содержит в себе скрипты и тетрадки, которые могут быть полезны при подготовке датасетов. 

## Prepare annotations

Данный скрипт может выполнять несколько задач. Для этого необходимо выставить следующие константы в начале файла:
- THRESHOLD - отвечает за минимальный порог по отсеиванию масок
- ALLOWDED_CATEGORIES - разрешенные категории, для объединения их масок (только внутри категории). ВАЖНО! Учитывать id и названия категорий как в аннотации
- CATS_PRIORITY - приоритет категорий при наложении масок. На один пиксель изображения приходится только одна категория, которая находится ближе к краю сцены.
- CATS_IDS_ORIG - Можно задать словарь с id и названиями категорий, необходимый при объединении двух аннотаций.
- IMG_IDS - список из двух списков, соответствующих айдищникам картинок, аннотации которых необходимо объединить.

При запуске скрипта необходимо указать:
- --annotation_path - путь к первой аннотации
- --second_annotation_path - путь ко второй аннотации
- --new_annotation_path - путь к новой аннотации

Далее будут  описаны основные функции скрипта:
- Исправляет айдишники картинок и аннотаций в правильном порядке (1, 2, ...)
```
first_annotation.fix_ids()
```

- Объединяет аннотации с учетом **ALLOWDED_CATEGORIES**
```
first_annotation.concatenate_masks()
```

- Объединяет две аннотации в одну с учетом **CATS_IDS_ORIG** и **IMG_IDS**
```
join = JoinAnns()
join.add_annotations(first_annotation, second_annotation, new_annotation_pth)
```

- Убирает все наложения масок в аннотации с учетом приоритета категорий **CATS_PRIORITY**
```
first_annotation.join_annotations()
```

- Показывает статистику распределения категорий в аннотации
```
first_annotation.show_statics()
```

- Разделяет аннотации на train и test с учетом количества тестовой выборки *test_size*
```
first_annotation.split_train_test(test_size=261, folder_pth='datasets/nkb_v1.0_full/3141')
```
